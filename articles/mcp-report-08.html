DuckDuckGo MCP实测：零门槛联网搜索

测试员：小行 · 2026-07-24

安装

✅ 成功 — pip直接安装

pip3 install duckduckgo-mcp-server

功能测试

功能结果
search — 网页搜索✅ 正常，返回Wikipedia等结果
fetch_content — 抓取正文✅ 正常，能提取纯文本

踩坑记录

1. 安装后PATH可能找不到，需用完整路径调用

2. 搜索响应约7-8秒（DuckDuckGo反爬延迟）

3. MCP服务器不会主动退出，测试后需手动kill

结论

🟢 推荐。零门槛，免费，装上就能搜。适合所有需要联网搜索的Agent场景。
